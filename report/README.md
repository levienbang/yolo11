# Báo cáo cuối

- `overleaf/`: mã nguồn LaTeX và các hình của báo cáo; tệp chính `main.tex`.
- `bao-cao.zip`: bản ZIP để tải trực tiếp lên Overleaf, có cùng nội dung với `overleaf/`.

Sau khi nhập ZIP vào Overleaf, chọn `main.tex` làm tệp chính. Bản này đã chuyển ma trận nhầm lẫn lên Chương 4; phụ lục A dẫn tới mã nguồn GitHub.
